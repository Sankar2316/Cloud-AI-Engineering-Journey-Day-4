# 🚀 Day 04 – Compute Services (EC2 / Virtual Machines)

---

## 📌 Overview

On Day 04, I explored **Compute Services**, which allow users to run applications on virtual machines in the cloud.

---

## ☁️ What is Compute in Cloud?

Compute refers to the ability to run applications and workloads on virtual servers without managing physical hardware.

---

## 🖥️ Amazon EC2 (Elastic Compute Cloud)

Amazon EC2 is a service that provides **resizable virtual servers (instances)** in the cloud.

---

## 🔑 Key Features of EC2

* Scalable compute capacity
* Pay-as-you-go pricing
* Multiple instance types
* Secure with key pairs
* Elastic IP support

---

## ⚙️ Core Concepts

* **Instance** → Virtual server
* **AMI (Amazon Machine Image)** → OS template
* **Instance Type** → CPU, RAM configuration
* **Key Pair** → Secure login (SSH)
* **Security Group** → Firewall rules

---

## 🔐 Security in EC2

* Security Groups (inbound/outbound rules)
* Key-based authentication
* IAM roles for access control

---

## 🔵 Azure Virtual Machines

Azure VM is Microsoft’s compute service similar to EC2.

### 🔑 Features:

* Flexible VM sizes
* High availability
* Integrated security
* Auto scaling
